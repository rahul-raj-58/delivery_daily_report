⚠ Open via a local server, not file://

Your browser blocks cross-origin requests from file:// pages. Run this one-time command in Terminal from the folder where this file is saved:

python3 -m http.server 8080

Then open http://localhost:8080/catalog-dashboard.html in your browser.
